# 절삭유 순환 자동 프로그램

가공하지 않고 대기 중인 장비에서 절삭유를 일정 간격으로 **켰다(M08) → 껐다(M09)** 를 반복해,
탱크 안 절삭유가 고여서 썩는 것을 줄이기 위한 NC 프로그램입니다.
RESET을 누르기 전까지 하루 종일 계속 반복합니다.

```
절삭유  ON ┌──┐          ┌──┐          ┌──┐
          │  │          │  │          │  │
      OFF ┘  └──────────┘  └──────────┘  └──── ... (RESET 누를 때까지)
           1분    10분     1분    10분
```

- **축 이동 없음, 주축 회전 없음.** 절삭유 ON/OFF와 대기(G04)만 합니다.
- 컨트롤러 화면이 한글을 못 읽는 경우가 많아서 프로그램 안의 주석은 영문으로 적었습니다.

## 파일

| 파일 | 컨트롤러 | 설명 |
|---|---|---|
| `fanuc/O5000_coolant_circulation.nc` | FANUC (Custom Macro B 옵션) | **기본 추천.** ON/OFF 시간(분), 반복 횟수를 맨 위에서 설정 |
| `fanuc/O5001_coolant_circulation_simple.nc` | FANUC (매크로 옵션 없음) | 가장 단순한 버전. O5000 실행 시 매크로 관련 알람이 나면 사용 |
| `siemens/COOLANT_CIRC.MPF` | SIEMENS 840D sl / 828D | 지멘스 장비용 |

## 설정 방법

### O5000 (FANUC 매크로 버전)

프로그램 맨 위 3줄만 바꾸면 됩니다.

| 변수 | 의미 | 기본값 |
|---|---|---|
| `#1` | 절삭유 **ON** 시간 (분) | `1.0` |
| `#2` | 절삭유 **OFF** 시간 (분) | `10.0` |
| `#3` | 반복 횟수 (`0` = 무한 반복) | `0` |

- 30초만 켜고 싶으면 `#1=0.5`
- ON/OFF 시간을 0 이하로 넣으면 알람(3001/3002)이 뜨고 멈춥니다.

### O5001 (FANUC 단순 버전)

`G04 X60.` (켜진 시간), `G04 X600.` (꺼진 시간)의 숫자를 **초 단위**로 직접 수정합니다.
끝의 `M99`가 프로그램 처음으로 돌아가게 해서 무한 반복합니다.

### COOLANT_CIRC.MPF (SIEMENS)

`CL_ON_MIN`, `CL_OFF_MIN`, `CL_REPEAT` 값을 O5000과 같은 방식으로 수정합니다.

## 사용 순서

1. **프로그램 번호 확인** — 장비에 이미 O5000 / O5001이 있으면 비어 있는 번호로 바꿔서 넣으세요.
2. 메모리카드 / USB / DNC로 장비에 입력합니다.
3. **처음엔 짧은 시간으로 시험 운전** — 예: `#1=0.2`, `#2=0.5` (12초 ON / 30초 OFF)로
   켜지고 꺼지는 시간이 맞는지 눈으로 확인한 뒤 원래 값으로 돌려놓습니다.
4. 문을 닫고 AUTO(MEM) 모드에서 **사이클 스타트**.
5. **중지할 때는 RESET.**
   - 피드홀드는 쓰지 마세요. 절삭유가 켜진 상태로 멈춰 있을 수 있습니다.
   - RESET 후에도 절삭유가 나오면 조작반의 절삭유 OFF 버튼을 누르거나 MDI에서 `M09`를 실행하세요.

## 주의사항

- **절삭유 M코드** — 일반 절삭유는 표준 M08/M09입니다. 스핀들 관통 절삭유(TSC), 샤워 쿨런트 등
  다른 노즐로 쏘고 싶으면 장비마다 M코드가 다르니 장비 매뉴얼을 보고 바꾸세요.
- **G04 시간 단위** — FANUC `G04 X`는 기본적으로 초 단위입니다. 다만 파라미터 3405#1(DWL)이 1이고
  회전당 이송 모드면 주축 회전수 단위로 바뀌어, 주축이 멈춘 상태에서는 대기가 끝나지 않을 수 있습니다.
  3번 시험 운전에서 시간이 정상인지 꼭 확인하세요.
- **간격을 너무 짧게 잡지 마세요** — ON/OFF가 너무 잦으면 펌프 모터 기동 횟수가 늘어 부담이 됩니다.
  OFF는 몇 분 이상으로 두는 것을 권장합니다.
- **노즐 방향** — 노즐이 문 틈이나 창 쪽을 향하면 무인 상태에서 밖으로 샐 수 있으니 확인하세요.
- **절삭유 수위** — 수위가 낮으면 펌프가 공회전할 수 있습니다. 장시간 돌리기 전에 수위를 확인하세요.
- **가동 상태로 집계됨** — 프로그램이 도는 동안 장비는 "자동운전 중"입니다.
  가동률 모니터링 시스템을 쓰고 있다면 가동 시간으로 잡힐 수 있습니다.
- 장비를 쓰려면 RESET 후 원래 가공 프로그램을 선택하면 됩니다.

## 부패 방지 추가 팁

- 절삭유 위에 뜬 습동유(트램프 오일)가 공기를 막아 세균이 번식하기 쉽습니다. 오일 스키머로 걷어내면 효과가 큽니다.
- 탱크에 에어 펌프(기포기)를 달면 장비 운전과 상관없이 24시간 산소를 공급할 수 있습니다.
- 농도가 너무 낮아도 잘 썩으므로 굴절계로 농도를 주기적으로 확인하세요.
